# Dra. Emanuelle Morais — Odontologia (Santos, SP)

Landing page institucional para a Dra. Emanuelle Morais, cirurgiã-dentista em
Santos/SP.

## Direção visual

- **Conceito:** "clínica-litorânea" — clareado, luminoso, editorial, em vez do
  padrão "consultório escuro/tons terrosos" já usado nos outros projetos da
  pasta. Base clara em tom de areia/creme, tinta marinha profunda só para
  texto/detalhes, um único accent vibrante em coral (não teal/terracota, que
  já aparecem em outros projetos).
- **Tipografia:** `Bodoni Moda` (serifada editorial, presença) + `Plus Jakarta
  Sans` (geométrica, calorosa) — combinação não usada nos demais projetos.
- **Layout:** hero assimétrico com parallax de fotos reais do consultório,
  storytelling em capítulos ao rolar a página, faixa cheia de coral para
  depoimento/CTA, e um motivo gráfico de linha do horizonte (onda) como
  assinatura visual recorrente entre seções.
- **Stack:** Next.js (App Router) + Tailwind v4 + `motion` (Framer Motion),
  seguindo convenção do monorepo.

## Rodando localmente

```bash
pnpm install
pnpm dev
```
